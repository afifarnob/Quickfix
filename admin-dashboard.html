📧 How to Send Files via Email:

  1. Click any export button above to download the file
  2. Open your email client (Gmail, Outlook, etc.)
  3. Create a new email to yourself or your team
  4. Attach the downloaded file
  5. Send the email

💡 Backup Tips:

  • Export data regularly (weekly or monthly)
  • Keep backups in a safe location (cloud storage, email, external drive)
  • JSON format preserves all data including images
  • CSV format is good for reports and spreadsheets
  • HTML format is great for printable reports
